Tutorial

HTML

HTML besteht im Wesentlichen aus öffnendem Tag, Content und schließendem Tag. Sie wird verwendet, um die Struktur von Websites zu definieren.

CSS

CSS ist eine Stylesprache, die dazu verwendet wird, um HTML Elemente zu stylen. Besteht immer aus einer Eigenschaft und einem Wert.

Flexbox

Flexbox ist ein CSS-Modul, mit dem sich flexible und moderne Layouts sowie die Ausrichtung von Elementen innerhalb eines Containers extrem einfach gestalten lassen.

Spezifitätsregeln

Die Spezifitätsregeln bestimmen, welches CSS-Stil auf ein HTML-Element angewendet wird, wenn mehrere Regeln darauf zutreffen.


Die Spezifität wird durch die Anzahl der Selektoren in einer Regel bestimmt. Je spezifischer eine Regel ist, desto höher ist ihre Priorität.
